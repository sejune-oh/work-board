# 디자인 기준 v2 제안: "작업대"

상태: 제안. 아직 `docs/design.md`와 `globals.css`에 반영하지 않았습니다. 시안은 [mockups/overview-v2.html](mockups/overview-v2.html).

요청: "좀 더 개발자스럽고 깔끔하게". 지금의 아침 현황지(세리프 표제, 따뜻한 종이, 종이 결)는 잡지처럼 읽힙니다.
지킬 것: 한눈에 보는 위계, 주의에만 쓰는 강조색 하나, 쉬운 한국어, 상태는 점 + 이름, AA 대비와 키보드 초점, 라이트·다크.

## 두 방향

| | A. 터미널 | B. 작업대 (추천) |
| --- | --- | --- |
| 톤 | 어두운 화면 우선, 프롬프트(`$ 개요`)와 ASCII 괘선, 로그처럼 읽히는 화면 | 차가운 회색 바탕 위 흰 판(카드) 몇 장, 표와 목록 중심의 정밀한 도구 |
| 글꼴 | Nanum Gothic Coding(한글 고정폭) 전부 + IBM Plex Mono | IBM Plex Sans KR 하나로 표제·본문, IBM Plex Mono는 번호·숫자·날짜·단축키 |
| 색 | 흑연 바탕, 녹색 프롬프트, 주의는 주황 | 회색 6단 + 상태 4색, 주의는 신호 주홍(인주 색을 차갑게 다듬은 값) |
| 밀도 | 매우 높음, 줄 높이 28px | 높음, 표 줄 36px, 구역 간격 16px |
| 기억할 한 가지 | 화면 전체가 명령줄 | 주의 줄 왼쪽의 2px 주홍 거터(diff 변경 줄 표시처럼) + 모든 화면 단축키 |

**B를 추천하는 이유.** 개발자가 매일 쓰는 도구(코드 리뷰 화면, 이슈 트래커)의 문법인 표, 거터, 단축키, 고정폭 번호를 가져오면서도
한글 본문은 비례폭으로 남겨 기획·운영 담당도 읽기 편합니다. A는 개발자 느낌은 가장 강하지만 한글 문장(한 문장 현황, 회의 할 일)이
고정폭에서 읽기 힘들고, Nanum Gothic Coding은 굵기가 두 개뿐이라 위계를 만들기 어렵습니다. B는 글꼴을 3개에서 2개로 줄여 가볍고,
지금 컴포넌트 구조를 그대로 두고 토큰과 몇 가지 규칙만 바꾸면 됩니다.

## 글꼴과 크기

Hahmlet를 빼고 IBM Plex Sans KR(400–700) + IBM Plex Mono(400–600). 기본 글자 14px로 한 단계 줄입니다.

| 단계 | 크기 / 줄 간격 | 예 |
| --- | --- | --- |
| `display` | 22px / 1.4, 600, 자간 -0.015em (휴대폰 19px) | 한 문장 현황 |
| `title` | 18px / 1.4, 600 | 화면 제목, 이슈 패널 제목 |
| `heading` | 13.5px / 40px 높이, 600 | 카드 머리 |
| `body` | 14px / 1.55 | 본문 |
| `ui` | 13.5px | 표 제목, 메뉴 |
| `meta` | 12px Mono 또는 12–12.5px Sans | 번호, 경과, 보조 |
| `figure` | 28px Mono 500 | 핵심 숫자 |

`eyebrow`(자간 넓힌 머리말)는 없애고 카드 머리 옆 `muted` 설명으로 바꿉니다.

## 간격과 모양

4px 단위 유지. 화면 여백 24px(휴대폰 16), 구역 사이 16px, 카드 안쪽 14px. 모서리: 표식 2px, kbd·버튼·입력·태그 3–4px, 카드·패널 6px.
상단 막대 48px 고정(sticky), 옆 메뉴 224px 흰 판.

## 컴포넌트

- **틀(shell)**: 옆 메뉴 맨 위에 조직 전환(`acme-health ⌄`), 메뉴마다 hover 시 단축키(`g o`, `g m` …). 상단에 `acme-health / 개요` 경로, 검색 `/`, 밝게·어둡게 두 칸 토글.
- **이슈 카드**: 흰 판 + 1px `rule`, 모서리 4px. hover는 `hover` 바탕만(그림자 없음). 첫 줄 Mono 번호, 상태는 점 + 이름을 카드 안에 표시.
- **상태 표시**: 7px 점 + 이름 12.5px `ink-soft`. 변경 없음(크기만).
- **주의 표시**: 도장 → "깃발(flag)". 주홍 글자 + 45% 주홍 1px 테두리, 3px 모서리. 긴급만 `accent-wash` 바탕. 긴급이면서 시작 전인 줄에는 왼쪽 2px 주홍 거터.
- **표·보드**: 손봐야 할 일은 열 머리(`저장소 #번호 / 제목 / 상태 / 담당 / 경과`)가 있는 표. 묶음 머리는 깃발 + 개수 + 이유. `j`/`k` 이동, Enter로 패널. 휴대폰은 두 줄 카드형.
- **이슈 패널**: 머리 48px에 Mono 번호와 `닫기 Esc`. 속성은 테두리 있는 2열 표(GitHub 옆 정보처럼).
- **개요 머리**: Mono 한 줄(날짜 · 열린 일 · 주기 4/14일째) → 22px 문장(주의 숫자는 주홍 Mono, 밑줄 없음) → 4칸 숫자 판. "멈춤" 칸은 위쪽 2px 주홍 줄 + 주홍 숫자.
- **최근 흐름**: 시간 열이 왼쪽에 고정된 로그 형태.
